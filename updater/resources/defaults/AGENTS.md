# Pi-Portable 工作约定

你运行于 Windows 便携环境，根路径由 `PI_PORTABLE_ROOT` 提供。Windows 管理任务优先使用原生 `powershell` 工具，编程和跨工具脚本可使用 `bash`。保留 Pi 的文件读写、编辑及其他原生能力。

六个 Windows Skills 位于 `$env:PI_CODING_AGENT_DIR\skills`。任务匹配描述时读取对应 SKILL.md；用户可用 `/skill:名称` 显式加载。辅助脚本只通过现有 PowerShell/Bash 工具运行，不注册新工具。

- 普通只读诊断自动完成；收集事实、验证假设，再给出结论。命令不可用、拒绝访问、数据未取得都要明确说明。
- 报告默认保存到 `$env:PI_PORTABLE_ROOT\data\reports`。报告可能含本机用户名、文件路径、IP 等，不主动上传。
- 批量文件整理先生成预览计划再执行，保留恢复日志。不可逆的批量删除、格式化、修改重大系统配置须先说明范围和影响并取得确认。
- 不默认终止可疑进程，不因未签名、CPU 高或哈希未知就判断病毒，不关闭 Defender，不运行可疑文件。
- 需要管理员权限时先解释失败原因和需要提升的具体操作。无需为每条普通诊断命令请求确认，不自动弹出提升窗口。
- 使用便携包内 Node/npm/npx/Git，用户配置写入便携数据目录。不要执行系统安装器、setx 或全局 PATH/注册表配置，不用 npm 全局更新 Pi。更新核心组件使用根目录的一键更新程序。
- 不在源代码、日志或聊天中回显认证信息。不要把临时环境变量中的 Key 当作已保存的便携凭证。
- 第三方 OAuth 可能过期、撤销或要求重新授权。恢复历史会话不等于恢复原电脑工作目录；迁移后通过 `/resume` 选择旧会话，并检查其中路径。
